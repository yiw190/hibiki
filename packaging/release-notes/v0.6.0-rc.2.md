**Release candidate 2 for 0.6.0: pasting screenshots and files into the composer, clearer errors, solo renders that solo one track, and editable agent rules.** Everything from v0.6.0-rc.1, plus the changes below.

### Install
Install `Hibiki-0.6.0-rc.2.pkg` (macOS) or `Hibiki-0.6.0-rc.2-setup.exe` (Windows) over v0.5.x or v0.6.0-rc.1, then restart REAPER so the new bridge and panel load. `hibiki doctor` should show `0.6.0-rc.2`. Installing a package switches the machine back to release mode.

### New
- **Paste into the composer**: Cmd+V (Ctrl+V on Windows) with files copied in Finder / Explorer attaches them as files instead of pasting their names. A screenshot or any image with no text beside it is saved as `screenshot-<time>.png` in the panel's scratch folder and attached. Rich text that also carries a picture still pastes as text.
- **Agent rules ship with defaults**: setup copies the shipped rules to `~/.config/hibiki/brain/defaults.md`, where you can edit or delete any of them. Upgrades update only the rules you haven't touched, keep your edits, don't bring back deleted ones and add new ones at the end. `rules.md` holds your own rules (`off:` / `[id]` overrides still work). The MCP server sends the combined text when a client connects, so Gamut and every MCP client get it. `hibiki rules [edit|off|on|reset]`.

### Changed
- **Errors say what happened**: when a reply fails, the panel shows the message and its code, for example `Connection lost (connection_lost)` or `Slow down (rate_limited)`, instead of a bare "error".
- **Version history** shows the project's name on top, with the full path on hover.
- Gamut prerequisites: sign in with a Gamut account; Gamut brings its own containers and models (your own API keys are optional). The README spells out what `--mcp-only` installs.

### Fixed
- **A reply that recovers keeps running**: Gamut restarts a runtime that dies mid-reply and the reply streams on. The panel used to end the reply at the error. Now it keeps the reply open, notes "(resumed)" in it when more output arrives, and closes it after 120 s or at your next message if it never resumes, so its changes still get a Version history title.
- **`render` with `solo_indices` soloed every selected track**: REAPER solos all selected tracks together when one of them is soloed, so with several tracks selected each solo render came out as the same mix. The bridge now solos only the listed tracks.

### Known
- Apple's `DLSMusicDevice` crashes playback when more than one instance runs in a project. Keep one, or set the others offline.
- Pasting on Windows is covered by tests but not yet tried on a desktop.
- Signing and notarization of the installers are still to come.

### Upgrading
Install over v0.5.x or v0.6.0-rc.1. If you were in dev mode, the installer switches you back to this release.
