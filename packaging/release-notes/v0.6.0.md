**Hibiki 0.6.0: version history, a playback meter, audition racks, Ears, shared agent rules, arranging without scripts, and services that show up as Hibiki.** This is the first stable release since v0.5.0 and includes everything from v0.5.1-rc.1 and v0.6.0-rc.1–rc.3, plus the changes below.

### Install
1. **REAPER first**: [reaper.fm](https://www.reaper.fm/download.php). Both installers refuse to continue without it.
2. **Hibiki**:
   - macOS: `Hibiki-0.6.0.pkg`.
   - Windows (10 1803+, 64-bit): `Hibiki-0.6.0-setup.exe`. It installs per user and needs no admin rights.
   - Neither installer is signed yet. On macOS go to Privacy & Security and choose **Open Anyway**. On Windows, at the SmartScreen prompt choose **More info**, then **Run anyway**.
3. **Restart REAPER** so the new bridge, panel and meter load. `hibiki doctor` should show `0.6.0`.

### New in 0.6.0 (since rc.3)
- **Services show up as Hibiki, not Python**:
  - macOS: the bundled Python now runs from `Hibiki.app` (bundle id `io.github.yiw190.hibiki`, with the Hibiki icon). Login Items list the MCP service, the gateway and the watchdog as **Hibiki** instead of "python3" and "bash", and privacy prompts (files on an external drive, Documents) name Hibiki.
  - Windows: the supervisor runs as `Hibiki.exe` and the services as `HibikiConsole.exe`, with the Hibiki icon. Task Manager and Settings → Apps → Startup show **Hibiki** instead of "Python".
- **Tool line**: an agent that titles a tool call with a multi-line shell command (Codex) no longer draws the command over the reply below it. The line stays one line.

### Highlights since v0.5.0
- **Version history** (rc.1): after every agent reply that changed the project, a copy is kept in `<project folder>/.hibiki/history/`, titled with the reply's first sentence. **Go to** switches to any version and can be undone. Each reply is one undo point labelled with what changed.
- **Measure playback** (rc.1): `Hibiki_Meter.jsfx` on the monitoring FX measures what you play (LUFS, true peak, correlation, bands, per bar) and the next message carries it. It never renders.
- **Audition rack** (rc.1, rc.3): an agent puts audible alternatives on lanes of one track. Switch with a click or keys 1–9; **Keep N** keeps one variant, including every track of a layered one.
- **Ears** (rc.1): renders the time selection from the master, measures it and attaches the result to your next message.
- **Agent rules** (rc.1, rc.2): `/remember <rule>`, editable shipped defaults, and every agent (Gamut, Codex, Claude Code, Kimi, Gemini, any MCP client) gets the same rules.
- **Composer** (rc.2, rc.3): paste copied files and screenshots with Cmd+V / Ctrl+V. Typed text stays when you click elsewhere, and Enter that commits a pinyin composition no longer sends.
- **Arranging tools** (rc.3): `item` splits, deletes, duplicates, trims, moves between tracks and sets fade shapes. `envelope` reads and writes a beat range. `status` reports the selection. `transport goto` jumps to a beat or marker. `render` takes a `format`.
- **One reply, one project** (rc.3): edits and renders aimed at a different project tab than the one a reply started on are refused.
- **`hibiki stop` / `start`, updates from the panel, `hibiki use dev`** (0.5.1-rc.1): turn the services off and on, check and install updates from Agent settings, and test a git checkout with the package's Python.
- **Long chats stay light** (0.5.1-rc.1): the panel draws the last 60 messages and loads earlier ones on request.

### Changed
- `item` uses `fade_in_sec` / `fade_out_sec` (was `fade_in` / `fade_out`); `transport` returns `position_sec` and `position_beats` (was `position`). (rc.3)
- `run_lua` stops a snippet that is still running Lua after its `timeout`. (rc.3)
- Errors in the panel show their message and code. (rc.2)

### Known
- Apple's `DLSMusicDevice` crashes playback when more than one instance runs in a project. Keep one, or set the others offline.
- Privacy permissions you gave "python3.12" on macOS are asked once more, now for Hibiki. Without a Developer ID signature, an update that changes the Python binary can ask again.
- Pasting and version-history pruning on Windows, and the Hibiki names in Task Manager, are covered by tests and CI but not yet tried on a desktop.
- Signing and notarization of the installers are still to come.

### Upgrading
Install over v0.5.x or any 0.6.0 candidate. Scripts that pass `fade_in` / `fade_out` to `item update` or read `position` from `transport` need the new names. If you were in dev mode, the installer switches you back to this release.
